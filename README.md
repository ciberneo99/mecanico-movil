# Austin Mobile Mechanic / Mecánico Móvil Austin

Sitio estático bilingüe (EN/ES) publicado en Netlify.

## Flujo
1. Editar contenido en `tools/config.js` y `tools/data/*.js`.
2. Regenerar: `node tools/build.js`
3. Commit y push a `main` → Netlify publica automáticamente.

Vista local: `node tools/serve.js`
